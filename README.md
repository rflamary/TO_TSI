# Transport optimal en traitement du signal et des images

Ce document est une introduction rapide au transport optimal pour le traitement
du signal et des images. Il a été rédigé par Julie Delon et Rémi Flamary pour
compléter la page [Histoire du traitement du signal et des
images](https://gretsi.fr/historique) du GRETSI. Le code latex source ets
disponible en licence CC BY-SA 4.0 et le code python qui a été utilisé pour
générer les figures est disponible en license MIT.
